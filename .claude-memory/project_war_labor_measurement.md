**★2026-07-07 이미지 조사로 부분 수정 — 규격(spec) 발견**: 같은-이름 애매 후보의 **99.7%(3,201/3,210)가 마스터 unit(30T/100T 등 포장)으로 구별**되고, 실제 송장 이미지(452002 확인)에 **규격 컬럼이 인쇄돼 있음**(같은 품명 2쌍이 100C/30C, 30C/500C로 구별). war는 invoice_body 스키마에 spec 컬럼 자체가 없어 매칭에 못 씀 → **애매 재선택 노동의 메커니즘 = 사람이 눈으로 규격을 봄**. "송장에 답 없음" 결론은 이름-다른 애매(63.1%)와 규격 미인쇄분에만 유효. 우리 V3 랭킹은 이미 spec 사용(+2.2pp, 낮은 spec 캡처율에서). **상한 = 같은-이름 애매 행 월 ~2,400건, 실현 ∝ spec 캡처율(③행검출·파인튜닝과 연동) — war가 구조적으로 못 하는 첫 실측 기반 차별화 후보. 이미지 파일럿으로 상한 측정 필요.** war 자동매칭이 규격 몰라 틀린 건 → 사람 교정이 되는 구조라, spec-aware 매칭은 "교정 건수 감소" 후보(빈도 랭킹스왑 기각과 별개 — 새 정보 사용).
